# API-Sentinel Backend

## Backend Contribution

This section documents the Python backend components:

- pi/database.py - database engine and session setup
- pi/models.py - database models
- pi/parser.py - API request/traffic parsing
- pi/schemas.py - request and response schemas
- pi/services.py - backend service logic
- pi/routers.py - API endpoints and ingestion routes
- pi/main.py - FastAPI application entry point

These components support API traffic ingestion, parsing, persistence, alert handling, and runtime security analysis.
